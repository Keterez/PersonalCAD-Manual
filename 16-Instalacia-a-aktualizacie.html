Inštalácia, spúšťanie a aktualizácie

Ktorú verziu tento manuál opisuje#

Manuál opisuje aktuálne vývojové zdroje 0.2.5. Podľa posledného pokynu používateľa sa testujú cez npm start a ďalšie balenie do EXE je odložené. Označenie verzie v package.json ani push zdrojového kódu nevytvárajú nový inštalátor alebo verejné vydanie.

Podoba programuStav zaznamenaný pri príprave manuálu
Zdrojový kód 0.2.5Aktuálne rozhranie a funkcie tohto manuálu; spustenie cez npm start
Lokálny inštalátor 0.2.4Nepublikovaný, starší než posledné opravy zdrojov; neobsahuje celý aktuálny manuál
Verejný aktualizačný kanálPublikované vydanie 0.2.1; jeho označenie latest nie je tvrdením o novších lokálnych zdrojoch

Staršie zdrojové záznamy môžu uvádzať aj lokálne zostavenia 0.2.2 a 0.2.3. Pri diagnostike vždy napíš presnú verziu a či používaš zdroje, inštalátor alebo win-unpacked. Samotný názov PersonalCAD nestačí na určenie dostupných funkcií.

Spustenie aktuálnych zdrojov 0.2.5#

Podmienky: kompletný zdrojový priečinok projektu, funkčné Node.js s npm a nainštalované npm závislosti. Pri prvom získaní závislostí je potrebné pripojenie na ich stiahnutie. Bežné lokálne modelovanie po príprave nevyžaduje cloudový účet.

V termináli otvor priečinok projektu a spusti:

npm install
npm start

npm install je potrebné po prvom klonovaní alebo pri zmene závislostí; nemusíš ho opakovať pred každým spustením. npm run dev je tiež vstup do vývojového spustenia. Nepoužívaj starý EXE, ak chceš otestovať novú funkciu dostupnú iba v zdrojoch.

Výpočet CAD používa pribalené lokálne WebAssembly jadro OpenCASCADE. Bežné spustenie nevyžaduje samostatnú inštaláciu Fusionu, cloudovej CAD služby, Qt ani kompiláciu C++ backendu. Git je potrebný pre prácu so zdrojovým repozitárom a synchronizáciu projektov, nie ako podmienka každého geometrického výpočtu.

Ak PowerShell blokuje skript npm.ps1, použi zodpovedajúci npm.cmd alebo terminál Command Prompt; nemeň kvôli tomu naslepo systémovú bezpečnostnú politiku. Vývojové ukončenie terminálu môže ukončiť aj aplikáciu, preto najprv ulož dokumenty a zavri ju bežným spôsobom.

Windows inštalátor#

Pre dostupné publikované vydanie použi oficiálny repozitár vydaní PersonalCAD-Releases. Je oddelený od pracovných projektov. Pri príprave tejto kapitoly bol verejne publikovaný inštalátor 0.2.1; odkaz na neexistujúci inštalátor 0.2.5 tu zámerne nie je.

  1. Ulož dokumenty a zavri bežiaci PersonalCAD.
  2. Spusť overený Windows x64 Setup z konkrétneho vydania, ktoré chceš inštalovať.
  3. Zvoľ cieľový priečinok a dokonči sprievodcu. Inštalácia je určená pre používateľský účet a umožňuje výber umiestnenia.
  4. Podľa ponuky použi odkazy na ploche alebo v ponuke Štart.
  5. Po spustení skontroluj verziu v nastaveniach aktualizácií.

Inštalátor neobsahuje tvoje osobné projekty ani prihlasovacie údaje. Nainštalovaný program nepotrebuje Node.js. Pracovné dokumenty sú samostatné súbory; pred manuálnym upgradom je rozumné mať ich uložené mimo priečinka programu.

Aktuálne zostavenia sú nepodpísané vydavateľským Windows certifikátom. Nepovažuj neznámy rovnomenný súbor z cudzieho zdroja za dôveryhodný iba preto, že sa volá Setup. HTTPS a kontrolný súčet riešia iné vlastnosti než podpis vydavateľa. Táto dokumentácia neodporúča plošne vypínať ochranu systému.

Nové vydanie s rovnakou identitou aplikácie je určené na inštalovanie cez existujúcu verziu bez predchádzajúceho odinštalovania. Skutočný upgrade na inom fyzickom PC sa však nesmie považovať za otestovaný len na základe kontroly obsahu inštalátora. Pred inštaláciou maj uložené pracovné súbory.

Priečinok win-unpacked#

Ak dostaneš rozbalenú testovaciu zostavu, spúšťaj PersonalCAD.exe spolu s celým jej priečinkom, najmä resources a ďalšími knižnicami. Samotné skopírovanie EXE nie je prenosná distribúcia. Chýbajúce súbory môžu spôsobiť prázdne okno, chýbajúci modul alebo nefunkčné CAD jadro.

Settings → Application updates#

Ikona Nastavenia / Settings je v hornej lište. Sekcia Application updates zobrazuje Version a stav kontroly. Aktualizačný postup je dostupný v zabalenej Windows aplikácii. Vývojové spustenie hlási Updates are available in the installed application.; neaktualizuje pracovnú kópiu zdrojov ani nespúšťa automatický git pull.

Zväčšiť obrázok ↗

Snímka aktuálneho spustenia cez npm start. Version 0.2.5 označuje bežiace zdroje; neaktívne tlačidlá tu neznamenajú dostupnosť alebo inštaláciu vydania 0.2.5. Rozbalený Update source ukazuje adresár vydaní aplikácie, nie súkromný projektový repozitár.

Bežný postup aktualizácie#

  1. Klikni Check for updates.
  2. Ak je dostupná novšia stabilná verzia, over oznámené číslo verzie.
  3. Klikni Download. Sleduj priebeh a počkaj na The update is downloaded and verified.
  4. Ulož dokumenty a klikni Install and restart.
  5. Prebehne bežná kontrola zatvorenia: lokálne uloženie a zapnutá synchronizácia projektov. Až úspešné odsúhlasené zatvorenie spustí inštalátor.

Automatická kontrola pri štarte sama nespúšťa download ani inštaláciu. Rovnako obyčajné zatvorenie programu nesmie nainštalovať aktualizáciu, ktorú si nespustil tlačidlom Install and restart. Ak zatvorenie zrušíš alebo sa nepodarí bezpečne dokončiť, aktualizácia zostáva v stave pripravenom na ďalší pokus.

Sťahovanie kontroluje metadáta vydania a SHA-512 súčty; neoverený download nesprístupní inštaláciu. Podporované sú novšie stabilné číselné verzie, nie downgrade ani prerelease. Rozhranie nemá modelovací Undo pre inštaláciu programu; návrat verzie nie je krok späť v CAD histórii.

Update source#

Rozbaľ Update source. Dostupné sú Release directory, Check for updates on startup a Save source.

  • Release directory je HTTPS priečinok obsahujúci latest.yml, nie odkaz na jeden .exe, .blockmap alebo priamo na latest.yml.
  • URL nesmie obsahovať meno/heslo, token, query parametre ani fragment. Nezadávaj sem URL súkromného pracovného projektu.
  • Po zmene poľa použi Save source; kým je nastavenie rozpracované, tlačidlá Check/Download/Install sú zablokované.
  • Vypnutie startup kontroly nemení ručnú dostupnosť Check for updates.

Prednastavený verejný kanál používa repozitár vydaní. Ak obsahuje iba 0.2.1 a ty spúšťaš novší lokálny program, up to date znamená „na zvolenom kanáli nie je vyššia dostupná verzia“, nie „lokálny zdroj bol automaticky zabalený a zverejnený“.

Nastavenie zdroja a startup kontroly sa ukladá na tomto počítači mimo pracovných projektov. Pri chybe nastavenia sa nezískava prístupový token zo synchronizácie projektov. Aktualizačný server a Git prenos pracovných návrhov sú oddelené mechanizmy.

Kde zostávajú dáta#

  • Documents / PersonalCAD Projects: predvolený koreň lokálnych a registrovaných projektov; skutočná cesta závisí od presmerovania systémového Documents.
  • Súbory zvolené cez Choose another location…: na tebou vybranom mieste, nemusia byť v tomto koreni.
  • Používateľské dáta aplikácie: nastavenia aktualizácií, register synchronizovaných projektov a cache podkladov. Nie sú súčasťou zdrojového repozitára projektu.
  • Prihlásenie GitHub: Git Credential Manager alebo SSH nastavenie daného počítača.

Rozhranie nedáva príkaz na vymazanie všetkých používateľských dát pri každej inštalácii. Konfigurácia inštalátora ich pri odinštalovaní automaticky nemaže; to však nie je náhrada zálohy vlastných súborov. Pri čistení priečinkov nerozlišuj dáta len podľa toho, či majú v názve PersonalCAD.

Prenos aplikácie kamarátovi alebo na druhý PC#

Program a projekty prenášaj ako dve odlišné veci. Druhému PC daj platný inštalátor alebo kompletný testovací priečinok pre príslušnú verziu. Pre aktuálne vývojové 0.2.5 potrebuje zdroje a závislosti, kým nebude výslovne vytvorené nové vydanie. Osobné návrhy otvorí cez natívne súbory alebo Git projekt.

Tvoj GitHub účet, tokeny ani celý používateľský dátový priečinok aplikácie sa kamarátovi nekopírujú. Každý sa prihlasuje vlastným spôsobom a musí mať udelené oprávnenia k súkromnému projektu. Druhý počítač má vlastné grafické nastavenia; stiahnutie modelu nezaručí rovnaké FPS na inom hardvéri.

Čo je úloha vydavateľa#

Príkazy npm run pack:win a npm run dist:win pripravujú rozbalený program/inštalátor zo zdrojov. Samy nič nepublikujú. Zmena verzie, testy zdrojov, kontrola skutočného zabaleného programu, porovnanie payloadu a až potom zverejnenie sú samostatné kroky. Build nesmie používateľovi predstierať overenie inštalácie na inom PC.

Pri aktuálnom pokyne je nové EXE balenie 0.2.5 odložené. Ak nájdeš tlačidlo alebo funkciu iba v tomto manuáli, najprv skontroluj verziu a spôsob spustenia, nie iba nastavenie aktualizačného kanála.
