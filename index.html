PersonalCAD — používateľská príručka

Táto príručka opisuje PersonalCAD 0.2.5, vývojovú verziu aplikácie. Text je po slovensky; názvy tlačidiel a polí zachovávajú jazyk, ktorý sa naozaj zobrazuje v aplikácii. Starší Windows inštalátor nemusí obsahovať všetky uvedené funkcie. Verzie a aktualizácie →

Začni prakticky: vytvor 3D dosku s otvorom alebo nakresli schému a LED dosku. Oba návody obsahujú hotový natívny príklad na otvorenie a vlastné skúšanie.

Ako sú pracoviská prepojené#

Mechanika

Skica → 3D operácie → Telesá → Zostava

Elektronika

Knižnica → Schéma → PCB → 3D PCB / výroba

PCB from Face prepája mechanický obrys s doskou. Update 3D model vloží PCB do zostavy. ElektroSkica má samostatný dokument.

Skica opisuje geometriu; modelovacia operácia z nej môže vytvoriť alebo upraviť teleso. Komponent zoskupuje diely zostavy a nesie ich umiestnenie či spojenia. Elektronická schéma a PCB patria do spoločného .pcb.json dokumentu. Knižnica určuje vzťah medzi symbolom, pinmi a fyzickými padmi. ElektroSkica má vlastný dokument .eskica; jej vodiče sa automaticky nemenia na PCB siete.

Ako čítať postupy#

  • File → New → 3D model znamená postupne otvoriť ponuku a zvoliť položky.
  • Ctrl+S znamená držať Ctrl a stlačiť S. Skratky nástroja obvykle vyžadujú aktívne kresliace plátno; písanie do vstupného poľa má prednosť.
  • OK / Apply potvrdzuje zmenu podľa konkrétneho panela. Cancel / Esc zvyčajne ruší aktuálny príkaz, Undo vracia už potvrdenú úpravu. Výnimky sú uvedené pri nástroji.
  • Obrázky zachytávajú skutočné rozhranie verzie 0.2.5 na generických cvičných dátach. Žltý alebo priehľadný náhľad pred potvrdením ešte nie je uložená operácia.
  • Pri každej kapitole sú uvedené hranice implementácie. Osivené položky neznamenajú hotovú funkciu a táto príručka nepotvrdzuje úplnú zhodu s Fusion.

O tejto príručke#

Toto je verejný web používateľského manuálu. Obsahuje dokumentáciu a generické cvičné príklady; pracovné projekty ani zdrojový kód aplikácie sa tu nezverejňujú.

Rozsah zdokumentovaných príkazov a spôsob overenia nájdeš v prehľade funkcií. Dokumentácia nie je vyjadrením percentuálnej spoľahlivosti aplikácie. Pri hlásení problému uveď verziu, pracovisko, presný postup, očakávaný výsledok a ideálne malý pracovný príklad; návod na diagnostiku pomôže odlíšiť výber, viditeľnosť, obmedzenie nástroja a chybu výpočtu.
